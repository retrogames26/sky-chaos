# Sky Chaos: Worst Airline Simulator

A playable 3D first-person and cockpit flight cooperative airline simulator built with **Three.js**, **Vite**, **TypeScript/React**, custom **3D Rigid-Body & Capsule Collision Physics**, **Firebase Auth & Cloud Firestore** (with local authoritative Express API fallback), and **Real-Time WebSocket Multiplayer**.

---

## Local Setup & Build Commands

```bash
# Install dependencies
bun install   # or npm install

# Run full-stack development server (Express + WebSocket + Vite on port 3000)
npm run dev

# Build production bundle (outputs to ./dist for Cloudflare Pages)
npm run build
```
